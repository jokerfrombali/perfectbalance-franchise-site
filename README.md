# Perfect Balance — сайт франшизы (прототип)

Многостраничный сайт франшизы доставки правильного питания на Astro: главная с калькулятором окупаемости,
14 коммерческих страниц, страницы городов (эталон — `/goroda/krasnodar/`), блог на 100 статей по SEO-ядру.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # боевая сборка в dist/
```

Превью на GitHub Pages собирается `npm run build && node scripts/preview-build.mjs` и закрыто от индексации.
Данные, помеченные на сайте «уточнить», — допущения до получения цифр от компании.
